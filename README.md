# S.A.V.E.
**Smart Ambulance Vectoring Engine**

Deployed - https://s-a-v-e-zeta.vercel.app/

An emergency routing system that dispatches ambulances across a city map using Dijkstra's algorithm. Supports a fleet of 3 units, real-time road blocking, triage priority levels, and mid-route hijacking for critical calls.

Built without STL — raw arrays, manual queues, and a custom priority queue.

S.A.V.E. (Smart Ambulance Vectoring Engine) is an advanced Emergency Routing System. It dynamically calculates optimal transit paths for medical dispatches, featuring real-time road blockage handling, multi-unit fleet management, and a dynamic triage system that can preemptively hijack units for critical emergencies.

Developed by Shah Manav Amit. The system's backend is engineered entirely using fundamental C++ data structures. It deliberately avoids standard template libraries (STL) to explicitly demonstrate the core mechanics of memory allocation, array-based queues, and graph traversal.
